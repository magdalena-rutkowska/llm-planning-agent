# LLM-Powered Planning Agent (Individual Project)

## Purpose

This application implements an LLM-powered planning agent based on the design proposal developed earlier in the Intelligent Agents module. The agent receives a goal, plans a sequence of actions, retrieves and processes data, and produces an output aligned with the chosen domain.
